# Balamurugan Daily Routine — Installable PWA

This is the installable version of the routine checklist.

## Important
A PWA must be served from an HTTPS web address. Opening index.html directly from your Downloads folder will not enable installation.

## GitHub Pages setup
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. In GitHub: Settings -> Pages.
4. Choose Deploy from a branch, select the main branch and / (root), then Save.
5. Open the generated HTTPS Pages URL in Chrome on Android.
6. Chrome menu -> Add to Home screen / Install app -> Add.

The app stores checklist progress in the browser's local storage.
